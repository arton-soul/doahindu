Kebijakan Privasi Doa Hindu

Terakhir diperbarui: 5 September 2026

Doa Hindu dikembangkan oleh Dearyoti dan disediakan untuk digunakan sebagaimana adanya.

Data yang disimpan di perangkat

Aplikasi menyimpan favorit, koleksi, catatan pribadi, riwayat dan posisi baca, serta pengaturan tampilan secara lokal di perangkat. Data tersebut tidak dikirim oleh Dearyoti ke server dan tidak dicadangkan ke cloud oleh aplikasi. Menghapus aplikasi akan menghapus data lokal tersebut.

Pembaruan konten

Aplikasi dapat menghubungi GitHub Pages melalui HTTPS untuk memeriksa dan mengunduh pembaruan database konten. Permintaan jaringan dapat mengungkapkan informasi teknis standar, seperti alamat IP, kepada penyedia layanan jaringan.

Layanan pihak ketiga

Aplikasi menggunakan layanan Google berikut:

  • Google Mobile Ads untuk menampilkan iklan;
  • User Messaging Platform untuk mengelola pilihan privasi iklan bila diwajibkan;
  • Firebase Analytics untuk statistik penggunaan dan performa aplikasi;
  • Firebase Cloud Messaging untuk mengirim notifikasi.

Layanan tersebut dapat memproses informasi perangkat, interaksi aplikasi, alamat IP, data diagnostik, serta advertising ID sesuai pengaturan, consent, dan kebijakan masing-masing. Iklan hanya diminta setelah aplikasi memperoleh status consent yang mengizinkannya.

  • Kebijakan Privasi Google
  • Privasi AdMob
  • Privasi Firebase

Notifikasi

Notifikasi bersifat opsional. Pada Android yang memerlukan izin, aplikasi menjelaskan kegunaannya sebelum meminta izin. Anda dapat menolak atau menonaktifkan notifikasi melalui pengaturan perangkat tanpa kehilangan fungsi membaca doa.

Keamanan dan tautan eksternal

Koneksi pembaruan konten dan tautan yang disediakan aplikasi menggunakan HTTPS. Tidak ada metode transmisi atau penyimpanan elektronik yang sepenuhnya bebas risiko. Tautan pihak ketiga tunduk pada kebijakan pengelolanya.

Anak-anak

Aplikasi tidak secara sengaja meminta anak-anak memberikan informasi pribadi. Orang tua atau wali dapat menghubungi pengembang jika memiliki kekhawatiran mengenai penggunaan aplikasi.

Perubahan kebijakan

Kebijakan ini dapat diperbarui untuk mencerminkan perubahan fitur, layanan pihak ketiga, atau ketentuan yang berlaku. Versi terbaru akan tersedia di dalam aplikasi dan melalui alamat kebijakan privasi publik aplikasi.
